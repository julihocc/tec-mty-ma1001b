# Lesson Notebooks

The lesson notebooks are designed as guided teaching materials, not short code
demos. Each notebook combines conceptual explanation, Python implementation,
decision interpretation, and practice.

## Repeated Lesson Pattern

Each notebook uses this structure:

1. Official MA1001B alignment.
2. How to use the lesson.
3. Learning goals.
4. Decision scenario.
5. Conceptual explanation.
6. Mathematical anchor.
7. Data and workflow notes.
8. Worked Python example.
9. Guided checkpoint.
10. Common mistakes.
11. Independent practice.
12. Interpretation template.
13. Exit ticket.

Students should run notebooks in order because early lessons establish shared
Python and data-handling habits used throughout the course. Instructors should
pause at the guided checkpoints and ask students to write before discussing the
answer.

## Pedagogical Use

For class sessions, use the notebooks as a sequence of short teaching episodes:

1. Discuss the decision scenario.
2. Explain the statistical idea.
3. Run and interpret a small code block.
4. Pause for a checkpoint.
5. Connect the result to a decision.

For homework, ask students to complete the independent practice and exit ticket.
Those responses are often better evidence of understanding than the code output
alone.
