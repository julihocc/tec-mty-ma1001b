# Notebook Rubric

Use this rubric for weekly notebooks and practical checks.

| Criterion | Excellent | Satisfactory | Needs Work |
| --- | --- | --- | --- |
| Reproducibility | Runs from top to bottom with clear setup and no hidden state. | Runs with minor ordering or environment issues. | Does not run or depends on unexplained manual steps. |
| Statistical reasoning | Explains the method, assumptions, and uncertainty in context. | Uses an appropriate method but explanation is incomplete. | Applies procedures mechanically or incorrectly. |
| Python workflow | Code is readable, organized, and uses appropriate pandas, NumPy, or SciPy tools. | Code is mostly correct but repetitive or hard to follow. | Code is fragile, unclear, or not connected to the analysis. |
| Interpretation | Converts results into a defensible decision statement. | Reports results but gives limited decision context. | Lists output without interpretation. |
| Reflection | Identifies a limitation or next question that matters. | Mentions a generic limitation. | Omits limitations or gives irrelevant caveats. |

Recommended weighting:

- Reproducibility: 20%
- Statistical reasoning: 30%
- Python workflow: 20%
- Interpretation: 20%
- Reflection: 10%
