# Capstone Technical Report Template

## Executive Summary

State the decision question, the main evidence, and the recommendation.

Write this section last. It should be understandable without reading the code.

## Context And Decision Question

Describe the practical decision and why uncertainty matters.

The reader should know who will use the result and what action is being
considered.

## Data

Describe the data source, unit of observation, variables, cleaning decisions,
and limitations.

Include a compact data dictionary for the variables used in the final analysis.

## Exploratory Analysis

Summarize the main patterns using tables and figures.

Do not include every chart you made. Include the charts that explain the
decision context or justify the modeling choice.

## Statistical Method

Explain the selected statistical method, assumptions, and why it is appropriate.

Name the parameter, effect, comparison, or model output that supports the
decision.

## Results

Present estimates, intervals, tests, model comparisons, or experimental results.

Report both statistical evidence and practical magnitude.

## Recommendation

Translate the statistical evidence into a decision recommendation.

Use a clear sentence:

```text
I recommend [action] because [evidence], with the limitation that [limitation].
```

## Limitations And Ethics

Discuss uncertainty, bias, representation, privacy, and what the analysis cannot
support.

Be specific. A useful limitation changes how the reader should use the result.

## References

Cite the dataset and any statistical or technical sources used.
